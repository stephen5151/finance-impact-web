## 一、一句话介绍

**「事件影响推演」是一个面向年轻人的财经事件解读网站：把最近的政治经济大事，翻译成普通人能听懂的"它会怎样影响我的生活"。** 不教炒股、不做投资建议，只帮年轻人看懂趋势。

## 二、它解决什么问题

年轻人每天刷到"美联储""通胀""油价上涨"这类新闻，但**看不懂这和自己的工作、工资、房租、消费有什么关系**。传统财经内容要么太专业、要么贩卖焦虑。

我们用一套固定方法把每件事讲清楚：

1. **用传导路径解释**，而不是抛结论吓人——事件如何先影响成本/利率，再影响行业/招聘，最后传导到你的生活；
2. **用"更可能"表达**，不做绝对化预言；
3. **用生活语言**，把"流动性收紧"翻译成"借钱变贵了"。

## 三、产品亮点

- **双入口**：① 浏览"最近事件"看完整推演；② 直接提问"这会不会影响我找工作"，得到结构化回答。
- **因果推演可视化**：每件事都画成一条手绘风格的"传导链"路线图，一眼看懂逻辑。
- **实时 + 可信**：自动抓取权威来源（美联储、BBC、华尔街见闻等），由 AI 筛选、翻译、生成结构化中文推演，每天更新，并标注来源。
- **价值观克制**：全站标注"不构成投资建议"，定位信息理解而非荐股。

## 四、我们如何使用大模型（即合作要赋能的核心）

模型是这个产品的引擎，承担四件事：

1. **理解用户的自然语言提问**并匹配到相关事件；
2. **把英文权威新闻翻译并改写成流畅中文**；
3. **按固定的 10 段结构生成完整推演**（发生了什么 → 为什么重要 → 传导路径 → 对年轻人的影响 → 短期/中期 → 风险提示）；
4. 保证输出**通俗、克制、不越界**（不预测涨跌、不给投资建议）。

这对模型的**中文表达、信息归纳、稳定结构化输出**要求很高——正是【厂商名称】模型的强项，也是我们希望深度采用贵司模型的原因。
